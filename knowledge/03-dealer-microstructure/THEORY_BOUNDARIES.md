# Dealer / Microstructure Theory Boundaries

## Supported uses

- explain inventory-risk incentives in formal dealer models
- explain adverse-selection components of spread
- explain liquidity/immediacy as an economic mechanism
- derive testable quantitative hypotheses when variables can be observed or proxied

## Unsupported leap

OHLC price action alone does not reveal:
- actual bank order books
- actual dealer inventory
- hidden resting orders
- exchange DOM for OTC spot/CFD feeds
- CVD/OI/liquidations unless those datasets are supplied

## Hypothesis template

Instead of: “dealer inventory is short, so price will rise.”

Use: “Under an inventory-risk hypothesis, observable proxy X should be associated with outcome Y under conditions Z. Define X/Y/Z and test on a specified dataset.”
