# RTM Operationalization Contract

## Current status

Framework shell is ready; exact canonical term definitions are pending official-source ingestion/recovery of existing internal RTM assets.

## When a source-backed concept is ingested

Capture:

1. source id and exact source location
2. source wording summarized without over-quoting
3. chart-condition definition
4. invalidation condition
5. whether the concept is inherently contextual/discretionary
6. a proposed operational rule if possible
7. differences between the proposed rule and original discretionary definition
8. test dataset requirements

## Forbidden shortcut

Do not convert FTR/BSZ/MPL/Quasimodo/Compression into ICT Order Block/FVG/Liquidity terms solely to make coding easier.
