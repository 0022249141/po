# RTM — Source-grounded definitions

This file contains only definitions that are directly supported by the currently verified RTM source note. It is not an RTM course reconstruction.

## `rtm_valid_swing`

- framework: `rtm`
- source_id: `readthemarket`
- source_state: `defined`
- source artifact: `knowledge/02-rtm/source-notes/readthemarket-official.md`

### Native definition captured

A valid swing is bounded from the **deepest point of a retrace** to the **furthest point of the subsequent advance**.

### What this definition establishes

It establishes how the current verified RTM source describes the endpoints of a swing.

### What it does not establish

It does not yet define:

- a minimum bar count;
- ATR or percentage thresholds;
- pivot confirmation delay;
- FTR/BSZ/MPL/Quasimodo/Compression construction;
- entry, stop, target or timeframe rules;
- whether the swing must break a previous structure level.

Therefore `rtm_valid_swing` is **defined**, but not `operational` or `backtest_ready`.

## Named RTM concepts still below `defined`

The official source verifies the names `FTR`, `BSZ`, `MPL`, `Quasimodo`, `Diamond`, and `Compression`. Their exact native construction rules are not captured by the current source note, so they must remain `source_noted` until exact source passages are ingested.

No ICT/SMC definitions are used to fill these gaps.
