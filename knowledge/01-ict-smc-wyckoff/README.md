- Community scripts may be inspected for implementation ideas but are not authorities for definitions.
- A concept is marked `operational` only when entry conditions, lookback, confirmation, invalidation and timing can be expressed without visual hindsight.
- Backtested claims belong in the Quant layer, not here.
